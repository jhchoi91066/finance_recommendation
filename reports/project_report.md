# 고객 재무 행동 360° — 행동으로 소득을 추정하고, 실데이터로 신용위험을 예측하다

> **한 줄 주제**: 두 개의 기둥. **(1) 합성 데이터(10년 1,330만 거래)** 로 *"고객이 어떻게
> 쓰는가"만으로 소득을 추정*하며 데이터 적정성·일반화를 검증하고, **(2) 실데이터(Lending
> Club 실제 대출 130만 건)** 로 *신용위험(연체)을 예측*하며 데이터 누수를 찾아 제거한다.
> 관통하는 정체성은 **"좋아 보이는 수치를 의심하고 정직하게 평가한다"**.
>
> 작성일 2026-06-15 · 모든 수치는 코드로 재현(`reports/*.json`, 차트는 `reports/figures/`).

## 0. 이 프로젝트의 핵심 메시지 (5가지)

단순한 분석은 "모델 돌려서 점수 냈다"에서 멈춘다. 이 프로젝트는 *문제를 의심하고,
데이터가 지탱하는 질문을 고르고, 결과를 돈·의사결정으로 번역*한다.

1. **데이터가 문제를 골랐다.** 신용점수·부채·DTI는 행동으로 예측 불가(R²≤0)였고,
   *소득*만 강하게 학습됐다(R² 0.56). → 타깃을 *증명한 뒤* 선택했다(§2).
2. **소득은 "얼마 쓰나"가 아니라 "어떻게 쓰나"에 있다.** 총지출만 쓰면 R² 0.17,
   지출 *변동성·지리적 이동·가맹점 다양성*까지 넣으면 0.56 (+230%) (§3).
3. **가장 필요한 사람에게 가장 안 된다(역설).** thin-file(신규) 고객은 이력이 짧아
   추정이 거의 불가(첫 100건 R² 0.08) — 행동 기반 방법의 근본 한계를 정량화(§3).
4. **합성에 머물지 않고 실데이터로 검증했다.** 실제 대출 130만 건(Lending Club)에서
   *데이터 누수를 찾아 제거*해 가짜 AUC 0.999 → 정직한 0.701을 보고했다(§3.5+).
5. **개인화·사기는 데이터의 한계를 *증명*하는 판단의 챕터로.** 추천은 인기도가 이기고,
   사기는 데이터가 지탱 못 함을 보였다. 버린 게 아니라 *판단의 근거*로 살렸다(§4).

## 2. 데이터 적정성 검증 — "어떤 재무 타깃이 행동으로 학습되는가"

코드 한 줄 짜기 전에, **행동 피처로 4개 타깃을 예측해 학습 가능성을 먼저 검증**했다
(합성 데이터에서 타깃이 노이즈면 프로젝트가 무너지므로).

| 타깃 | 행동 피처 CV R² | 결론 |
|---|---|---|
| credit_score | **−0.19** | 학습 불가 — 합성 생성기가 거의 독립 부여 |
| log_debt | −0.21 | 학습 불가 |
| dti(부채/소득) | −0.14 | 학습 불가 |
| **log_income** | **+0.39 → 0.56** | **강한 신호 → 척추로 선택** |

> 정적 속성(소득·부채·나이)만으로 신용점수를 회귀해도 R²는 0.03–0.08(≈0)이었다. 즉 이
> 데이터의 신용점수는 재무와 거의 무관하다. **"신용점수 예측"으로 갔다면 허위 결과를 냈을 것.**
> 타깃을 증명 없이 고르지 않는 것 — 이것이 데이터 적정성을 판별하는 능력이다.

## 3. 본편 — 거래 행동 기반 소득 추정 (`src/income_estimation.py`)

**과제**: 거래 내역에서 만든 26개 행동 피처로 사용자의 연소득을 추정(log 회귀, 5-fold CV).
**N = 1,219명**, 소득 중앙값 $40,012.

### 3.1 베이스라인 사다리 (우리의 평가 원칙)

| 모델 | CV R² (95% CI) | 중앙 오차 | ±20% 적중 |
|---|---|---|---|
| 평균 예측(naive) | −0.00 | $9,478 | 41.7% |
| 총지출만(단일피처) | 0.170 [0.03, 0.25] | $9,329 | 43.9% |
| **전체 행동(26피처)** | **0.562 [0.46, 0.62]** | **$7,076** | **54.7%** |

- **행동 풍부함의 가치**: '총지출만' 0.170 → '전체 행동' 0.562 (**+230%**).
- 의사결정 readout: **고소득(상위 25%) 식별 AUC 0.892** (신용한도 배정 등에 직접 활용 가능).

### 3.2 💡 인사이트: 소득은 "얼마"가 아니라 "어떻게" 쓰는가에 있다
permutation importance 상위 피처 (총지출이 1위가 아니다):

| 순위 | 피처 | 의미 |
|---|---|---|
| 1 | **std_amt** | 지출 금액의 변동성 |
| 2 | **n_states** | 거래가 발생한 주(州) 수 = 지리적 이동성 |
| 3 | **merchants_per_year** | 연간 이용 가맹점 다양성 |
| 4 | spend_per_year | 연간 총지출 |
| 5 | total_spend | 총지출 |
| 6+ | share_travel, n_mcc, share_entertainment | 여행·다양성·여가 지출 |

→ "부자는 많이 쓴다"가 아니라 **"다양하고 변동성 있게, 넓은 지역에서 쓴다"**가 소득의 신호다.
단순 지출액 프록시를 넘어서는 *행동의 구조*를 모델이 잡았다는 증거.

### 3.3 💡 인사이트(역설): 가장 필요한 고객에게 가장 안 된다
거래 이력 길이별 정확도:

| 사용한 이력 | R² | 중앙 오차 |
|---|---|---|
| 첫 25건 | 0.02 | $11,088 |
| 첫 100건 | 0.08 | $9,709 |
| 첫 1,000건 | 0.19 | $8,435 |
| 전체(평균 ~10,900건) | **0.56** | $7,076 |

→ 행동 기반 소득 추정은 **이력이 쌓인 기존 고객**에겐 유효하지만, *대안 소득검증이 가장
필요한* **신규·thin-file 고객**에겐 거의 작동하지 않는다. 행동 기반 방법의 근본 한계를 정량화.
*실무 함의*: "은행 기존 고객 대상 한도 재산정"엔 쓰되, "신규 고객 언더라이팅"엔 다른 신호 필요.

### 3.4 ⚖️ 세그먼트 공정성 (예측 편향, $ = 예측−실제 중앙값)

| 세그먼트 | 편향 | 함의 |
|---|---|---|
| 연령 ~35 | **−$3,033** | 청년 소득을 **과소** 추정 |
| 연령 65+ | **+$4,298** | 노년 소득을 **과대** 추정 |
| 성별(여/남) | −$187 / −$1,551 | 성별 편향은 작음 |

→ 연령 편향이 존재(청년 과소·노년 과대). 신용 의사결정에 쓰면 **adverse-action(규제)** 이슈가
되므로, 연령 보정·세그먼트별 캘리브레이션이 배포 전 필수. *이런 편향을 측정·보고하는 것 자체가
금융 도메인 성숙도의 신호.*

### 3.5 🔬 일반화 검증 — "합성 데이터를 넘어서도 통하는가" (`src/income_validation.py`)
가장 큰 약점: 합성 데이터의 R² 0.56이 *다른 분포*에서도 유지되는가? '거래행동+실제소득'을
모두 가진 실데이터가 공개돼 있지 않아 완벽한 외부검증은 불가능하다. 대신 데이터 안에서
**분포 이동(distribution shift)** 을 인위로 만들어 "모집단이 달라지면 무너지는가"를 측정했다.

| 검증 (학습 → 예측) | R² | 기준 대비 | 판정 |
|---|---|---|---|
| 무작위 CV (같은 분포 새 사용자) | 0.562 | — | 기준 |
| 지역: 서부→동부 / 동부→서부 | 0.571 / 0.424 | +2% / −24% | ✅ 견고 |
| 연령: 젊음→노년 / 노년→젊음 | 0.467 / 0.146 | −17% / −74% | ⚠️ 비대칭 |
| **소비수준: 저→고 / 고→저** | **0.138 / 0.055** | −75% / −90% | ❌ **붕괴** |
| Ablation: 상위3 피처 제거 | 0.507 | −10% | ✅ 견고 |

**해석(정직한 결론):**
- **지역엔 견고**: 거주 지역이 달라도 행동→소득 관계가 유지 → 일부 외부 일반화 근거.
- **피처에 견고**: 1위 피처(변동성·이동성·다양성)를 다 빼도 0.51 → *한 피처의 우연이 아니라
  여러 신호에 분산*된 견고한 관계.
- **소비 수준엔 붕괴(covariate shift)**: 저소비층만 학습하면 고소비층 예측 실패(R² 0.06).
  → **이것이 합성→실데이터 이전의 핵심 위험**: 실제 모집단의 *소비 분포가 다르면 성능이
  급락*하며, 도메인 적응(domain adaptation)·재캘리브레이션 없이는 그대로 못 쓴다.

> 즉 "잘 된다/안 된다"가 아니라 **"지역·피처엔 견고, 소비분포 이동엔 취약"** 이라는 *구조적 답*을
> 얻었다. 자기 모델이 어디서 깨지는지 아는 것 — 이것이 외부 타당성에 대한 정직한 검증이다.

## 3.5+ 실데이터로 옮겨 검증 — Lending Club 신용위험 (`src/credit_risk.py`)

합성 데이터의 최대 약점("진짜 세상에서도 통하나?")을 정면 보완하기 위해, **실제 P2P 대출
130만 건**(Lending Club, 2007–2018, 연체율 20.1%)으로 연체를 예측했다. 핵심은 *합성
데이터에서 갈고닦은 정직한 평가 원칙을 실데이터에서 그대로 재현*하는 것.

### 💡 데이터 누수의 대가를 실데이터로 실증
Lending Club엔 '대출이 끝난 뒤에야 아는' 컬럼(회수금·총상환액·미상환원금 등)이 섞여 있다.
이걸 피처로 쓰면 미래를 보고 과거를 맞히는 셈 → AUC가 가짜로 치솟는다.

| 모델 | ROC-AUC | PR-AUC | 의미 |
|---|---|---|---|
| L: **누수 피처 포함** | **0.9998** | 0.9998 | 가짜('커닝'). 흔히 하는 실수 |
| **A: 신청시점 차주정보만** | **0.701** | 0.374 | **정직한 실력**(실제 LC 모델 수준) |
| A+: A + LC 자체 등급/금리 | 0.704 | 0.378 | LC의 리스크 가격이 +0.003 → **거의 무의미** |

→ **누수의 대가 = AUC 0.30** (0.999 → 0.701). 시간 분할(과거 대출 학습→미래 예측)로 평가.
*추가 발견*: 차주의 기본 정보(소득·DTI·신용회전율)만으로 **LC의 독자 신용등급과 동등한** 예측력.

### 의사결정·공정성
- **승인율 운영점**: 위험순 정렬해 위험한 20%를 거절(승인율 80%)하면 승인군 연체율이
  21.7% → **17.2%**(0.79배)로 하락. 승인율 70%면 15.3%. → 실제 여신 승인 정책으로 직결.
- **공정성**: 저소득군 연체율 25.5% vs 고소득군 18.3%. 모델이 소득에 의존하므로 저소득층
  거절이 커질 수 있음 → adverse-action·금융포용 관점의 트레이드오프를 명시해야 한다.
- 상위 피처: installment·loan_amnt·revol_util·annual_inc·dti (실제 신용위험 동인과 일치).

> **이 챕터의 의미**: "합성에서만 했다"는 단 하나의 치명적 반론을 막는다. *같은 정직성
> 원칙이 실제 130만 건 대출에서도 작동*하며, 누수를 찾아 제거하는 능력을 실데이터로 증명했다.

### 모델 고도화 6가지 + 객관적 ablation (`src/credit_risk_advanced.py`)
모델을 "돌리기"에서 "실무급 마감"으로. 각 개선의 기여를 *객관적으로 측정*했다.

**개선별 AUC 기여 (ablation, test 평가)**

| 단계 | AUC | Δ |
|---|---|---|
| M0: v1 재현 | 0.6981 | — |
| M1: + 피처 엔지니어링(소득대비대출·상환부담률 등) | 0.6995 | +0.0014 |
| M2: + 네이티브 범주형 처리 | 0.7011 | +0.0016 |
| M3: + 하이퍼파라미터 튜닝(최종) | **0.7018** | +0.0007 |
| **합계** | | **+0.0037** |

**💡 객관적 결론(가장 정직한 부분): 모델 다듬기의 AUC 이득은 +0.004로 미미했다.**
이건 실패가 아니라 *발견*이다 — **성능 천장은 알고리즘이 아니라 데이터/피처가 정한다**는 §3.5+의
가설을 실험으로 확인했다. "튜닝하면 크게 오른다"는 흔한 기대가 틀렸음을 정량적으로 보였다.

**진짜 가치가 나온 곳 (정확도 아닌 신뢰성·실무성):**
- **해석가능 모델이 거의 동등**: 로지스틱(스코어카드형) AUC 0.692 vs LightGBM 0.702, **격차 0.01**.
  → 신용평가는 규제상 *설명 가능한 모델*을 요구하는데, 여기선 **설명가능성을 택해도 성능 손실
  거의 없음**. 실무적으로 매우 중요한 결론. (사유코드: *장기 대출·높은 상환부담·높은 소득대비대출*이
  연체위험↑ — 해석도 타당)
- **시간적으로 견고**: 롤링-오리진 검증(2014·2015·2016 예측) AUC **0.716 ± 0.010**. 단일 분할의
  운(運)을 제거하고 *낮은 분산*으로 안정성 입증.
- **캘리브레이션은 오히려 악화**(ECE 0.027→0.049): 모델이 이미 잘 보정돼 있었고, 검증구간과
  테스트구간의 시점 차이(drift) 때문. → *무지성 보정은 해롭다*는 것도 측정으로 확인(정직한 음의 결과).

> **고도화의 교훈**: 정직하게 개발하면 "숫자를 크게 못 올린다"는 사실 자체가 결론이 된다.
> 대신 *어디까지가 천장인지, 해석가능 모델로도 충분한지, 시간에 견고한지, 보정이 필요한지*를
> 증거로 답했다 — 이것이 "분석"과 "모델 개발"의 차이다.

### 실무 아티팩트 — 스코어카드 & SHAP 설명가능성
모델을 *은행이 실제 쓰는 형태*로 마감하고, 개별 의사결정의 근거를 제시했다.

- **신용 스코어카드** (`src/credit_scorecard.py`): WOE/IV 비닝 + 로지스틱을 PDO 점수로 변환.
  IV 1위는 우리가 만든 **loan_to_income(0.12)**. 5개 피처의 단순·해석가능 카드는 AUC 0.623
  (전체 모델 0.70 대비 해석가능성을 위해 일부 양보)이지만, **점수 구간별 연체율이 34.8% →
  10.9%로 단조 감소**하는 "좋은 카드"다. (`reports/figures/06_scorecard.png`)
- **SHAP 설명가능성** (`src/shap_explain.py`, LightGBM 내장 exact SHAP): 전역 중요도는
  term_months·inst_to_loan·dti 순(로지스틱 사유코드와 일치 → 방법 간 교차검증). 개별 대출도
  *"이 대출은 60개월 장기·높은 상환부담 때문에 위험 75%"* 처럼 **사유코드**로 설명 →
  ECOA adverse-action 고지에 직결. (`reports/figures/07_shap_summary.png`, `08_shap_reasons.png`)

> 한 장 요약은 [`reports/SUMMARY.md`](SUMMARY.md), 모든 차트는 `reports/figures/`.

## 4. 판단의 챕터 — 버리지 않은 추천·사기

### 4.1 추천: "개인화가 항상 답은 아니다" (`src/recommendation_eval.py`)
전체 1,219명·95% CI로 정직하게 재평가한 결과(기존 평가의 '정답을 후보에서 제거하는 버그' 수정):

| 모델 | NDCG@10 | 인기도 대비 |
|---|---|---|
| **인기도(baseline)** | **0.768** | 0% |
| NMF | 0.726 | −5.4% |
| SVD | 0.687 | −10.5% |

→ 희소 소매 거래는 주유소·마트 등 보편 가맹점이 지배해 **단순 인기도가 행렬분해를 능가**.
가맹점 단위 개인화의 한계 효용이 낮다는 *근거 있는 방향 전환*.

### 4.2 사기: "데이터가 지탱하지 못함을 증명" (`src/fraud_detection.py`)
- 정직한 **시간 분할**(2010–17 학습→17–19 예측): ROC 0.72 / PR-AUC 0.019(무작위 11배),
  검토 상위 0.5%로 사기 피해의 **19.3%($56K) 차단**.
- **평가 정직성**: 같은 데이터를 *랜덤 분할*로 보면 PR-AUC 0.044/ROC 0.90으로 **2.3배 부풀려짐**.
  짧은 구간까지 겹치면 0.89도 나옴(착시).
- **결론**: 합성·비정상성 라벨로는 견고한 사기 모델이 어렵다는 것을 *증명*. 데이터 적정성을
  판별하는 능력의 또 다른 사례(velocity 피처로 PR-AUC를 3배 올려본 뒤 내린 결론이라 더 설득력).

## 5. 가로지르는 강점 — 평가 방법론

세 모듈 전부에 동일 원칙을 적용했다: **베이스라인 대비로 말하기 · 시간/교차 검증 · 부트스트랩
신뢰구간 · 데이터 누수 차단 · 결과를 돈/의사결정으로 번역 · 세그먼트 공정성 점검.**
"좋아 보이는 단일 수치"를 신뢰하지 않는 태도가 이 프로젝트의 일관된 정체성이다.

## 6. 정직한 한계

1. **합성 데이터**: 절대 수치보다 *관계의 방향성·문제 구조*를 주장한다(데이터 현실성과 무관하게 참).
2. **소득 라벨은 단일 스냅샷**: 인과가 아닌 횡단면 상관. 소득 *변화* 추적은 불가.
3. **thin-file 한계**(§3.3): 신규 고객 적용엔 추가 신호(개설정보·외부데이터) 필요.
4. **N=1,219(사용자 단위)**: 해석가능 모델엔 충분하나 딥러닝엔 부적합.

## 8. 종합 요약 (실측 수치)

> **"10년치 1,330만 건 카드 거래에서, 어떤 재무 타깃이 행동으로 학습 가능한지 먼저 검증했다.
> 신용점수·부채는 합성 데이터상 노이즈(R²≤0)임을 밝히고, *소득*만이 학습됨을 확인해 문제를
> 선택했다.** 거래 행동 26개 피처로 연소득을 추정해 **R² 0.56(중앙오차 $7K, 고소득 식별 AUC
> 0.89)** 을 달성했고, *총지출만 쓰는 베이스라인 대비 +230%* 향상을 보였다. 핵심 발견은
> *소득이 지출 총액보다 지출의 변동성·지리적 이동·가맹점 다양성으로 더 잘 드러난다*는 것과,
> *thin-file 고객일수록 추정이 어려워지는 역설*을 정량화한 것이다. 연령 편향(청년 과소·노년
> 과대)까지 측정해 규제 관점의 한계를 명시했다."

핵심 키워드: 대안 소득검증 · 데이터 적정성 검증 · 행동 피처 엔지니어링 · 베이스라인 대비 lift ·
교차검증·신뢰구간 · thin-file 한계 · 세그먼트 공정성(adverse action) · 설명가능성.
